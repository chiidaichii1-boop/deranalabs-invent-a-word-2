## The word

**tabnesia (n.): the instant forgetting of why you opened a new browser tab.**

Everyone who lives in a browser has felt it: you open a fresh tab with a
clear purpose, and by the time it loads, the reason is gone. English had
no single word for that little blank — now it does.

## How it works

`main.py` (Python 3, standard library only) writes the word and its
one-line definition to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run

```sh
python3 main.py
```
